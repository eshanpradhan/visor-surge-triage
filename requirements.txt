# Versions this pipeline was developed and validated against.
#
# runtime.txt pins Python 3.11. Every package below publishes a Linux wheel for
# 3.11, so nothing should build from source; on 3.14 several have no wheels yet
# and pip falls back to compiling, which is what failed.
#
# torch, torchvision and lightgbm stay exactly pinned: those produce the model
# numbers, and the fp16 checkpoint was verified numerically against these
# specific builds. numpy and pillow are floors rather than exact pins, to give
# the resolver room to satisfy whatever torch asks for.
#
# Note on LightGBM and PyTorch: both bundle an OpenMP runtime, and on macOS any
# LightGBM call from a process that has imported torch segfaults. The app scores
# the clinical model in a subprocess (clinical_service.py) rather than pinning
# around the problem. See README.md.
